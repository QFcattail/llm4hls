## 遇到的问题与解决方案 (Issues & Resolutions)

### Q1: SSH 一度 Connection refused
- 现象：Vitis 装完后 SSH 短暂连不上（connection refused，非 timeout）。
- 原因：网络抖动（uptime 显示服务器没重启）。
- 解法：等几秒重连即恢复。

### Q2: AMD 官网火狐 Access Denied
- 现象：火狐注册 AMD 账号时被 Akamai CDN 拦截（Access Denied + errors.edgesuite.net）。
- 诊断：服务器 curl 用 Chrome UA 访问 AMD 注册页返回 200。火狐的"POST 重发确认"对话框触发的重复 POST 被 Akamai 判为异常。
- 解法：用户在 Chrome 里完成注册和下载。Chrome 服务器上已有（150 版）。

### Q3: synth 报 latency=0（PPA 分丢失）
- 现象：projection 题 baseline 和 candidate 的 latency 都是 0，导致 acceleration 无法计算，PPA 0.3 权重（0.6 分）没拿到。
- 初判：projection 可能是纯组合逻辑（一个时钟周期完成，HLS 报 latency=0）。这道题本身可能没有 PPA 优化空间。
- 影响：不阻塞当前进度（correctness + synth 的 1.4 分已到手）。PPA 主战场是 dotProduct_optimize 题。
- 待办：P4 前查清楚，确认是设计特性还是报告解析问题。
