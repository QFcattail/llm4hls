### 4. v0.7.0：token 分级开关 + per-call 埋点（P4-03 代码侧）

**设计原则（用户要求）：成品默认不限制、不优化；所有省 token 手段收进显式开关。**

- `--token-mode {full,balanced,aggressive}`，**默认 full = 逐字节同旧行为**
  - balanced：review（LLM#2/#7）+ select（LLM#5）关 thinking；砍掉 pre-csim
    review 的重复 description 注入
  - aggressive：再关 brief（LLM#3）+ propose（LLM#4）的 thinking；selector
    prompt 去掉静态 spec 块
- 大头定位：reasoning 占 completion 的 89%（dotProduct e2e：91k/102k），
  所以 `thinking.type="disabled"` 是主杠杆而非 prompt 裁剪
- DeepSeekClient：per-call `reasoning_effort` 覆盖（"off"→thinking disabled）+
  `last_usage` 快照
- **埋点（全模式默认开，纯观测）**：`llm_call` 事件补 model/prompt_tokens/
  completion_tokens/reasoning_tokens（架构 §12.2 spec 落地）；`route` 事件记
  token_mode；`kb_search` 事件补 hit_ids（P3-10 验证前提）
- TC-AGENT-016：full 无覆盖 / balanced review+select=off / aggressive 全 off +
  spec 块裁剪 / 无旋钮后端 TypeError 回退 / 未知模式拒绝。16/16 全过
