## 遇到的问题与解决方案 (Issues & Resolutions)
- **内置 WebFetch 全域名被挡**：根因是 harness 域名安全验证服务，不是网络不通。
  解法：写 `web_fetch.py` 走 Bash（已验证 Bash 网络畅通）。
- **conda python 无 html2text**：`pip install` 默认装到系统 3.10，conda 3.13 没有。
  解法：`/home/GPUclaude/miniconda3/bin/pip install html2text` 装入 conda。
- **全局 `npm install -g` 权限失败**：`/usr/lib/node_modules` 非 root 不可写。
  解法：MCP 配置用 `npx -y`（按需解析到用户缓存），不依赖全局安装。
