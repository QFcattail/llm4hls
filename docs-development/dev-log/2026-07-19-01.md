| 问题 | 根因 | 解法 |

| TUI 无得分 | TUI 只调 agent.run()，grade() 只在 CLI | agent 线程 run() 后接着 grade()，score 事件驱动 submit stat + 区域 C 打印 |

| 真实 DeepSeek 策略格式发散（历史问题） | 同名 prompt 不同采样格式不一 | 严格模板 prompt + 宽容解析器 + raw_head 诊断三保险（v0.3.2） |
