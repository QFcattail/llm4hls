# Title:AutoChip: Automating HDL Generation Using LLM Feedback

Authors:[Shailja Thakur](https://arxiv.org/search/cs?searchtype=author&query=Thakur,+S), [Jason Blocklove](https://arxiv.org/search/cs?searchtype=author&query=Blocklove,+J), [Hammond Pearce](https://arxiv.org/search/cs?searchtype=author&query=Pearce,+H), [Benjamin Tan](https://arxiv.org/search/cs?searchtype=author&query=Tan,+B), [Siddharth Garg](https://arxiv.org/search/cs?searchtype=author&query=Garg,+S), [Ramesh Karri](https://arxiv.org/search/cs?searchtype=author&query=Karri,+R)

[View PDF](https://arxiv.org/pdf/2311.04887) [HTML (](https://arxiv.org/abs/experimental)](https://arxiv.org/html/2311.04887v2)

> Abstract:Traditionally, designs are written in Verilog hardware description language (](https://arxiv.org/abs/HDL) and debugged by hardware engineers. While this approach is effective, it is time-consuming and error-prone for complex designs. Large language models (](https://arxiv.org/abs/LLMs) are promising in automating HDL code generation. LLMs are trained on massive datasets of text and code, and they can learn to generate code that compiles and is functionally accurate. We aim to evaluate the ability of LLMs to generate functionally correct HDL models. We build AutoChip by combining the interactive capabilities of LLMs and the output from Verilog simulations to generate Verilog modules. We start with a design prompt for a module and the context from compilation errors and debugging messages, which highlight differences between the expected and actual outputs. This ensures that accurate Verilog code can be generated without human intervention. We evaluate AutoChip using problem sets from HDLBits. We conduct a comprehensive analysis of the AutoChip using several LLMs and problem categories. The results show that incorporating context from compiler tools, such as Icarus Verilog, improves the effectiveness, yielding 24.20% more accurate Verilog. We release our evaluation scripts and datasets as open-source contributions at the following link [this https URL](https://github.com/shailja-thakur/AutoChip).
